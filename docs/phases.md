Main reference for app design: SmartTV client for Twitch

# phase 1 - livestream player with chat

pretty much what we have already

- hardcoded channel livestream video
- video quality picker
- channel metadata shown for a few seconds: name, avatar, stream title, category, tags, live indicator, time live, viewer count
- live chat with platform emotes and timestamps; randomized chat usernames colors
- new: disable screen button - audio only mode, nothing on the screen, can get back to normal by pressing any navigation button. main reference apply

# phase 2 - search and channel info

- home screen is a search bar, which allows to search by username
- search results are a grid of channels with channel name and avatar shown. click on a channel tile opens channel info page
- channel page: name, avatar, follower count, decription, live indicator
- if live - live stream preview block: preview image, stream title, category, tags, time live, viewer count

# phase 3 - VOD viewer

- channel page shows latest stream recordings (VODs) in a grid
- each VOD shows: preview image, title, category, tags

# phase 4 - discover tab

- streams and categories
- add search by category
- category page shows channels grid filtered by category

# phase 5 - login,

- login ability
- 'following' tab
- 'follow'/'unfollow' button on channel info page
